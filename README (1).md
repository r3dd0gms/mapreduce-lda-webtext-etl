# Question 2 dataset: South African news articles

`Q2_topic_modelling_lda.ipynb` reads **`news.zip`** from this folder. The zip holds the `.txt` news articles (in a folder called `sa_news/`).

`news.zip` was not in the uploaded assessment folder. Copy it here before running the notebook:

```
data/q2_news/news.zip
```

The unzipped copy is created in `data/q2_news/extracted_news/` and is git-ignored.
